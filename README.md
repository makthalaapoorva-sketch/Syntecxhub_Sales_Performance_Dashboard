# 📊 Superstore Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze retail sales, profit margins, regional performance, and top-performing product categories using the Superstore dataset.

Developed as part of the **Data Analytics Internship** at **Syntecxhub**.

---

## 📌 Project Overview
The objective of this project is to provide actionable business insights into sales performance and profitability. The dashboard enables stakeholders to track growth, evaluate regional demand, and identify top product categories to optimize business strategies.

---

## 🛠️ Tools & Technologies Used
* **Visualization & Modeling:** Power BI Desktop
* **Data Processing & Prep:** Microsoft Excel / Power Query
* **Data Source:** Public Sample Superstore Dataset (Kaggle / Tableau)

---

## 🔑 Key Features & Insights
* **Sales & Profit Tracking:** Overview of total sales, total profit, and overall profit margins.
* **Category Performance:** In-depth breakdown of sales across Technology, Furniture, and Office Supplies.
* **Geographic & Regional Analysis:** Regional sales breakdown to spot high-performing locations.
* **Customer Segment Insights:** Analysis of Consumer, Corporate, and Home Office segments.

---

## 📁 Repository Structure
* `Superstore_Sales_Dashboard.pbix` - Power BI Project File containing the data model, measures, and dashboard layout.
* `Sample_Superstore.csv` - The raw sales dataset used for analysis.
* `Superstore_Sales_Dashboard.pdf` - High-resolution PDF export/preview of the dashboard.
